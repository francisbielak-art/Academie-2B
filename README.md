# Académie 2B — Starter Expo (TypeScript)

Ce dépôt contient un starter minimal Expo + TypeScript pour l'application de self-défense (Krav Maga, Silat/Pencak, pao drills, condition physique).

Ce commit initialise la structure d'un projet Expo et quelques écrans d'exemple.

Commands
- yarn install
- yarn start

Structure
- App.tsx: point d'entrée
- src/screens: écrans d'exemple
- src/navigation: navigation stack

Remarques
- Remplacez les versions et ajoutez Firebase si nécessaire.
